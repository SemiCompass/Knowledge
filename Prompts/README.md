# プロンプト辞典

仕事でくり返し使うプロンプトを集めたものです。**1プロンプト＝1ファイル**で、カテゴリーごとのフォルダに入れます。
フォルダは何階層にしてもかまいません（大分類／小分類）。

```
Prompts/
├─ README.md            … この一覧
├─ _template.md         … ひな形
└─ ツール作成/            … 大分類
   └─ HTMLツール/        … 小分類
      └─ 階層要求の確認・回答収集ツール.md
```

## 使い方

1. 下の一覧から使いたいプロンプトを開く
2. 「プロンプト」欄をコピーし、`{{…}}` の部分を自分の内容に置き換えて Claude に貼る

## 追加のしかた

1. [`_template.md`](_template.md) を写して、カテゴリーのフォルダに `<内容がわかる名前>.md` で保存する
   （例 `調査/競合分析/競合比較.md`）。フォルダが無ければ作る
2. 下の一覧に1行足す

## 一覧

| カテゴリー | プロンプト | 用途 |
|---|---|---|
| ツール作成 ／ HTMLツール | [階層要求の確認・回答収集ツール](ツール作成/HTMLツール/階層要求の確認・回答収集ツール.md) | 階層化された要求のつながりを見せ、担当者の確認回答をCSVで集める汎用HTMLツールを作らせる |
